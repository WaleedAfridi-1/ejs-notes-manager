# 📝 Notes App

A minimal and modern Notes App built using **Node.js**, **Express.js**, **EJS**, and **Tailwind CSS**.  
This project allows users to create and view notes stored directly in text files using Node.js filesystem module (`fs`).

---

## 🚀 Features

- Create notes dynamically
- Store notes as `.txt` files
- View saved notes
- Clean modern dark UI
- Responsive design using Tailwind CSS
- Lightweight file-based storage (No Database)

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- Tailwind CSS
- File System Module (`fs`)

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/WaleedAfridi-1/ejs-notes-manager.git
```

### 2. Navigate into project directory

```bash
cd ejs-notes-manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node app.js
```

---

## 🌐 Run Locally

Open your browser and visit:

```bash
http://localhost:3000
```

## 📸 Features Overview

### 📝 Create Notes
Users can create notes with title and description.

### 📂 File-Based Storage
Each note is stored as a `.txt` file inside the `files` folder.

### 👀 View Notes
Click on any note card to open and read the full note.
